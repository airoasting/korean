로그 수집 에이전트(logpipe-agent) 설치 가이드 v2.3

1. 개요
이 문서는 사내 서버에 로그 수집 에이전트를 설치하고 중앙 로그 서버로 전송하도록 설정하는 방법을 설명합니다. 지원 OS는 Ubuntu 22.04 이상, Rocky Linux 9 이상입니다.

2. 사전 준비
- 설치 계정에 sudo 권한이 있어야 합니다.
- 중앙 로그 서버(log-collector.internal) 5044번 포트로 나가는 통신이 허용되어 있어야 합니다. 방화벽 정책은 인프라팀에 따로 신청합니다.
- 디스크 여유 공간이 2GB 이상 필요합니다. 전송에 실패하면 로그를 로컬에 임시 보관하기 때문입니다.

3. 설치
사내 패키지 저장소를 통해 설치합니다.
  sudo apt install logpipe-agent
설치가 끝나면 /etc/logpipe/agent.yaml 파일이 생성됩니다.

4. 주요 설정
- service_name: 서비스 식별자입니다. 대시보드 검색 기준이 되므로 팀 명명 규칙을 따릅니다.
- buffer_size_mb: 기본값은 512입니다. 트래픽이 많은 API 서버는 1024 이상을 권장합니다.
- exclude_fields: 개인정보가 담길 수 있는 필드(phone, email 등)는 반드시 여기에 추가합니다.

5. 문제 해결
에이전트는 실행 중인데 로그가 들어오지 않는다면 대부분 방화벽 문제입니다. 먼저 nc 명령으로 5044 포트 연결을 확인하십시오. 연결이 되는데도 수집되지 않으면 service_name에 공백이나 대문자가 들어갔는지 확인합니다.
